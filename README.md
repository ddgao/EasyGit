# EasyGit - IntelliJ IDEA Git 分支合并插件

## 项目概述

EasyGit 是一款 IntelliJ IDEA 插件，专为微服务项目开发设计，简化 Git 分支合并和 Tag 管理流程。

### 核心痛点解决

| 痛点 | 解决方案 |
|------|---------|
| 每次需要手动合并功能分支到 dev/test/main | 一键合并到指定环境或所有环境 |
| 多个微服务项目需要重复操作 | 批量选择多个仓库同时操作 |
| 打 Tag 需要手动计算序号 | 智能识别已有 Tag，自动累加序号 |
| 合并操作容易遗漏 | 操作历史记录，方便追溯 |
| 打完 Tag 需要手动记录 | 汇总展示所有创建的 Tag |
| 多仓库打 Tag 版本不同 | 支持为每个仓库设置独立的 Tag 名称 |

---

## 功能特性

### 1. 分支合并（基于远端分支）

- **分步合并**：功能分支 → dev / test / main
- **一键合并**：功能分支依次合并到 dev、test、main
- **基于远端分支**：合并目标使用远端分支（如 `origin/dev`），本地无分支时自动从远端创建
- 合并前自动 fetch 最新代码
- 冲突检测和提示，中断流程让用户手动解决
- 可配置是否自动 push
- 合并完成后自动切回原分支

### 2. 智能打 Tag（基于远端分支）

**Tag 基于配置的远端分支创建**（默认 `origin/main`），而非当前分支。

支持三种 Tag 格式：
- **正常版本**：`R_3.1.7`、`v1.0.0`（自动递增 patch 版本）
- **临时需求**：`R_3.1.6-P01`、`R_3.1.6-P02`（自动累加）
- **Hotfix**：`R_3.1.6-H01`、`R_3.1.6-H02`（自动累加）

**多仓库独立 Tag 名称**：
- 每个仓库可设置不同的 Tag 名称
- 支持批量设置统一 Tag 名称
- 支持重置为自动计算的建议值
- 切换 Tag 类型自动重新计算

### 3. 批量操作

- 支持同时选择多个 Git 仓库
- 进度条显示处理状态
- 结果汇总展示

### 4. 操作历史

- 记录每次合并/打 Tag 操作
- 包含时间、仓库、操作类型、结果
- 支持查看和清空历史

## 使用方式

### 方式一：项目目录右键菜单（推荐）

在 Project 面板中，右键点击项目目录：

```
右键项目目录 → EasyGit
    ├── 合并到 Dev
    ├── 合并到 Test
    ├── 合并到 Main
    ├── ─────────────
    ├── 一键合并所有环境
    ├── ─────────────
    └── 打 Tag...
```

**支持多选**：按住 Ctrl/Cmd 选中多个项目，右键可批量操作。

### 方式二：VCS 菜单

`VCS → EasyGit` 下有完整功能菜单。

### 方式三：工具窗口

底部 "EasyGit" 面板，提供可视化操作界面：
- 自动加载当前项目中的所有 Git 仓库
- 仓库列表（勾选要操作的仓库）
- 快捷操作按钮
- 操作历史查看

## 对话框说明

### 合并对话框

- 仓库选择表格（支持全选/取消全选）
- 源分支选择（只显示远端分支，如 `origin/feature-xxx`）
- 目标分支选择（远端分支）
- 合并前 Fetch 选项
- 合并后推送选项

### Tag 对话框

| 列 | 说明 |
|----|------|
| 仓库名称 | Git 仓库名 |
| 基准分支 | Tag 创建的基准远端分支（可配置，默认 `origin/main`） |
| 最新 Tag | 该仓库当前最新的 Tag |
| 新 Tag 名称 | 自动计算或手动输入的新 Tag 名称（可编辑） |
| 操作 | 点击"查看更多"查看最近 20 个 Tag |

**批量操作**：
- 输入 Tag 名称后点击"应用到所有仓库"
- 点击"重置"恢复为自动计算的建议值

## 配置说明

`Settings → Tools → EasyGit`

### 分支配置

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| 开发环境分支 | dev | 合并目标 DEV |
| 测试环境分支 | test | 合并目标 TEST |
| 生产环境分支 | main | 合并目标 MAIN |
| 打 Tag 基准分支 | main | Tag 基于此远端分支创建 |

### 自动化选项

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| 合并前自动 Fetch | ✓ | 确保获取远程最新代码 |
| 合并后自动 Push | ✗ | 自动推送合并结果到远程 |

### 仓库配置（可选）

用于底部工具窗口：
- 如果未配置：自动使用 IDEA 检测到的项目仓库
- 如果已配置：使用配置的仓库路径

## 开发指南

### 环境要求

- JDK 17+
- IntelliJ IDEA 2023.3+
- Gradle 8.5+

### 构建和运行

```bash
# 运行插件测试（启动新的 IDEA 实例）
./gradlew runIde

# 构建插件安装包
./gradlew buildPlugin
# 输出: build/distributions/EasyGit-1.0.0.zip

# 安装到正式 IDEA
Settings → Plugins → ⚙️ → Install Plugin from Disk
```
